# Frozen environment of Takagi & Nishimoto on the training server: `uv pip freeze` on the main venv
# (`.venv`, Python 3.10.13) that fitted the ridge decoders and generated the images of the thesis.
# Read it, do not install it. PyTorch is 2.0.1 built for CUDA 11.8 (the upstream environment
# pins 1.11.0, which has no kernels for the sm_89 GPUs of the server).
# The venv was first built by an earlier version of `scripts/setup_venv.sh` and then repaired by hand
# (numpy pinned to 1.26.4, a .pth file that makes `ldm` importable, `taming-transformers-rom1504`,
# CLIP weights fetched with wget). The script of this folder lists the repaired steps, which is why
# the list holds two taming packages: the git one is the first install, the rom1504 one is the
# one that works. `scikit-image==0.19.3` was installed by hand as well (SSIM needs `multichannel=`).
# The line starting with `-e` is the editable install of `codes/diffusion_sd1/stable-diffusion`
# (the path of the server is replaced by the relative one).
# There is no lock for the BLIP environment (`.venv_blip`, Python 3.9): it was deleted from the
# server to free disk before the locks were taken. Its versions are the ones pinned in
# `scripts/setup_venv_blip.sh`.
